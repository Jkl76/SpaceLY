# SpaceLY

Static site for booking creative spaces (student project).

Quick start
- Open the site: open [root/index.html](root/index.html) in your browser.
- Or run a simple local server from the `root` folder:

```bash
cd root
python -m http.server 8000
# then open http://localhost:8000
```

Notes
- CSS lives in `css/style.css` and JS in `JS/script.js`.
